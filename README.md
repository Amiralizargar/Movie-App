# 🎬 Movie Explorer

A movie discovery application built with Next.js, TypeScript, Tailwind CSS, and the TMDB API.

## Features

- 🔍 Search movies
- ⭐ Filter movies by rating
- 📅 Filter movies by release year
- 🎭 Filter by genre
- 📄 Pagination
- 🎬 Movie details
- ❤️ Favorites
- ▶️ Movie trailers
- ⏳ Loading states
- ❌ Error handling
- 📱 Responsive design

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- TMDB API
- Git & GitHub
- Vercel
